# Thermal Printer OS (Flutter Native)

100% Pure Dart/Flutter application for pocket and POS thermal printers.

## Highlights
- **Universal BLE Protocol**: Reverse-engineered `0x51 0x78` magic header, CRC8 polynomial `0x07`, Level 5 Deepen (9200µs pulse), 50ms chunk pacing.
- **In-Place WYSIWYG Editor**: Click and write directly on receipt paper without modal dialogs.
- **Photo Printing**: Upload photos with Floyd-Steinberg dithering and high-contrast thresholding.
- **Motivational Quotes**: Curated focus and discipline quotes with 1-tap shuffle.
- **Daily Agenda & Calendar**: One-tap Google Calendar agenda sync and custom timetable.
- **Gap & Spacing Control**: Adjustable vertical spacing blocks so text never overlaps.
- **Prominent Sticky Print Dock**: Fixed, unmistakable print button with live BLE connectivity indicators.
